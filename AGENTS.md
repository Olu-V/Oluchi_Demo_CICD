# AGENTS.md - Project Commands

## Project Setup
- Node.js v24+
- Playwright Test Framework

## Install Dependencies
```bash
npm install
npm run test:install  # Install browser binaries (first time only)
npx playwright install chromium
```

## Run Tests
```bash
npm test              # Run all tests (headless)
npm run test:headed   # Run all tests in headed mode
npm run test:smoke    # Run smoke tests only
npm run test:register # Run registration tests only
npm run test:login    # Run login tests only
npm run test:full-flow # Run full registration + login flow
```

## Debug Tests
```bash
npm run test:debug    # Run in debug mode
npm run test:ui       # Run with Playwright UI mode
npx playwright codegen # Generate code by recording actions
```

## View Reports
```bash
npm run report        # Open HTML test report
```

## Configuration
- Set `HEADLESS=false` in `.env` to run in headed mode
- Test data is auto-generated by `utils/testData.js` unless overridden in `.env`
